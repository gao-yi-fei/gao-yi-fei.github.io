**特殊收容措施：**项目应被保存于一基金会标准小型储存单元中，该容器应被置于Site-MC-23中与其许可等级匹配的低危异常收容区域。用于一般查阅与非实验研究时，仅限项目研究小组成员存取项目。仅当项目首席研究员或一名拥有4级及以上权限人员准许时，项目可被用于实验目的。



@@@@

@@@@



**描述：**SCP-MC-221是一成书，其名称为“诸神行记（第十二卷）——古老登神者之纷争”，共有2██页。项目的封面上有数道深浅不一的划痕，内部书页较为陈旧，部分书页存在不影响阅读的轻微破损；除此之外，项目于物理性质上与非异常成书无区别。项目以中古埃斯卡语记述了一则古埃斯卡神话的片断，该神话被认为是基于古埃斯卡史诗[[[clotsfoot-epics-col-3|《溪罗铎词》]]]的设定进行的再创作。



当一个具有主动语言能力的智能实体（记为SCP-MC-221-1）以古埃斯卡语吟诵项目中的特定内容，且SCP-MC-221-1周围16米内存在且仅存在另一个智能实体（记为SCP-MC-221-2）时，项目的异常效应即显现。项目的异常效应表现为以近似[[[SCP-MC-123|旁观状态]]]的一个或数个实体以SCP-MC-221-2为对象展开一系列特殊活动；SCP-MC-221-2在多数情况下不会受到上述实体的影响，或仅受到有限的影响。



有关项目的文字内容以及异常效应的详细信息，参见附录MC-221/1。



@@@@

@@@@



-----



@@@@

@@@@



**历史：**2025年9月15日，一支经济学与建筑学专业部门考古队伍于████进行实地勘探时，意外发掘到了项目。一位考古队员无意间吟诵了项目中的文字，随后[已编辑]，造成考古队长S███ U████轻伤，项目随后被认定为异常并被收容。



在对项目进行研究后，项目研究小组曾尝试搜索名为“诸神行记”的文学作品，但未有收获。

= **实验记录MC-221/1.01**



-----



**实验时间：**2025年10月█日 14:██



**实验人员：**D-65577（SCP-MC-221-1），D-4002D（SCP-MC-221-2）



-----



**实验内容：**D-65577与D-4002D被置于一露天空旷场地，其周围32米内的人员已净空。令D-65577吟诵项目第4页的如下文段



[[div class="papernote"]]

{{……传说的领域，就是这古埃斯卡的群岛，它是诗人、艺者与商人之乡。而在民众的上方，他们永远无法触及的边界之外，还有神意的敕裁。那是至上之神、写作与诗歌之神、修辞之神、吟游诗人神提恩歌思议·溪若妲赋词，和那逆位神憎戈息·拷罗焚词的不息的战争源起之处。……}}

[[/div]]



-----



**实验结果：**无明显现象。

[[/div]]



[[div class="jotting"]]

= **实验记录MC-221/1.02**



-----



**实验时间：**2025年10月█日 14:██



**实验人员：**D-65577（SCP-MC-221-1），D-4002D（SCP-MC-221-2）



-----



**实验内容：**在上一次实验后，令D-65577吟诵项目第28页的如下文段



[[div class="papernote"]]

{{……憎戈息就这样拖着祂的大剑踏过了米勒波底斯山，那山脚下的村庄、山坡上的牧人以及山顶的猎户都未能幸免。那来自死与狂的神，憎戈息就这样说道：“若你不愿见生灵遭受这般苦痛，你就现身与我一战！”天域里惟有回声与未知的轰鸣，那溪若妲赋词仍未现身……}}

[[/div]]



-----



**实验结果：**一旁观状态的附魔石剑从D-4002D左前方不远处出现，之后自东南向西北方向穿过D-4002D，D-4002D被略微击退。

[[/div]]



[[div class="jotting"]]

= **实验记录MC-221/1.03**



-----



**实验时间：**2025年10月█日 15:██



**实验人员：**D-65577（SCP-MC-221-1），D-4002D（SCP-MC-221-2）



-----



**实验内容：**在上一次实验后，令D-65577吟诵项目第79页的如下文段



[[div class="papernote"]]

{{……那雷电的斥候狂奔而来，却仍不及憎戈息半步之速。于是，憎戈息将祂那至忠诚亦至恶的三叉戟直彻入雨云之中，整个银灰色的下沉的天幕为之震动。下一刻，二千一百万匹呓语构成的坐骑就冲向人间，扑向那溪若妲赋词誓言保卫的溪罗蒂娜。先头的坐骑化身袭来，那为大敌的神就观看，见有一匹灰马，骑在马上的，名字叫……}}

[[/div]]



-----



**实验结果：**读至此处时，一阵风吹走了D-65577所持的项目。数秒后，超过██个旁观状态的马自D-4002D左后方冲出，将D-4002D冲击倒地，并持续对其造成微小伤害，直至12秒后在D-4002D右前方消失。D-4002D共损失12生命值。项目随后被回收。

[[/div]]



[[div class="jotting"]]

= **实验记录MC-221/1.04**



-----



**实验时间：**2025年11月█日 19:██



**实验人员：**D-65577（SCP-MC-221-1），D-320B0（SCP-MC-221-2）



-----



**实验内容：**D-65577与D-320B0被置于一露天空旷场地，其周围32米内的人员已净空。令D-65577吟诵项目第125页的如下文段



[[div class="papernote"]]

{{……“我不将认逆位为我的友。”溪若妲赋词威严地回答。憎戈息顿时震怒，他召来连三界之神都惧怕的权杖，向上挥舞，如雨一般的箭就出现在空中、停滞着。“溪若妲赋词，我命定与你决战至死，你此刻不得再逃，否则这无情的雨将毁灭你的所有子民！”憎戈息发出了终末的挑战……}}

[[/div]]



-----



**实验结果：**随着D-65577吟诵，D-320B0上方28-36米处开始出现旁观状态的实体箭，并随吟诵进度而快速增多，直至超过██00支。吟诵停止后，所有箭迅速向D-320B0移动，D-320B0随后被击中██00次，仅剩1生命值。

[[/div]]



[[div class="jotting"]]

= **实验记录MC-221/1.05**



-----



**实验时间：**2025年11月██日 10:██



**实验人员：**D-65577（SCP-MC-221-1），D-49011（SCP-MC-221-2）



-----



**实验内容：**D-65577与D-49011被置于一露天空旷场地，其周围32米内的人员已净空；D-49011身着基金会制式防具并被施以5分钟的缓慢IV效果。令D-65577吟诵项目第189页的如下文段



[[div class="papernote"]]

{{……那憎戈息与溪若妲赋词就这样大战，直至昼夜不再轮转，直至雪雨逆流而上，直至凡人生而复死。祂与祂的大战是文字的战争，每一方都有无穷的思想泉源，也正因无穷而难分胜负……}}

[[/div]]



-----



**实验结果：**无明显现象。实验结束4小时后，D-65577报告称其出于未知原因丧失了使用古埃斯卡语的能力。

[[/div]]

= **实验记录MC-221/1.06**



-----



**实验时间：**2025年12月█日 22:██



**实验人员：**Dr. Larc Henson（EAPD历史科主任，SCP-MC-221-1）



-----



**实验内容：**此实验未获项目研究小组正式授权。在其周围32米均无人的情况下，Larc Henson在前述实验的场地吟诵了项目第2██页的如下文段



[[div class="papernote"]]

{{……神之间战争的终结，却是凡人所致。只消一句话，那至上之神与逆位神的不可磨灭的分歧便融化，那明与暗、善与恶的平衡便终于合一。}}



{{那凡人说：“憎戈息与溪若妲赋词，你等古老登神者……”}}

[[/div]]



-----



**实验结果：**Dr. Larc Henson被发现[数据删除]。项目风险等级已更新为Danger。
