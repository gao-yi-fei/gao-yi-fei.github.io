**特殊收容措施：**基金会应封锁SCP-MC-239附近--1000--10000格的区域。任何进入该区域的未授权人员都应对其进行C级记忆删除处理。任何派往SCP-MC-239执行任务的基金会人员都应接种//ꙮ-5685//模因疫苗。SCP-MC-239-1附近50格内，每10格应放置一个斯克兰顿现实稳定锚。未经A级人员授权，任何人员禁止进入SCP-MC-239-1。



基金会应每天对SCP-MC-239-2生命体征进行监测，如果SCP-MC-239-2的苏醒程度达到60%，基金会应立即启动//绿洲协议//。关于该协议详见于附录SCP-MC-239-B。



**描述：**SCP-MC-239分为SCP-MC-239-1和SCP-MC-239-2。



SCP-MC-239-1为一座位于████沙漠中的神殿。经推测，该神殿建于█████年前。该神殿由土、草方块、金块、钻石块、绿宝石块、石头、沙石以及█种未知方块构成。该神殿门口挂着一座由黄金制成的雕像，该雕像含义未知。该神殿存在认知危害，任何未接种疫苗观看SCP-MC-239-1的人都会患上严重的精神分裂症，并试图袭击附近的一切未被SCP-MC-239-1模因污染的人。进入SCP-MC-239-1的内部后会有一座通往SCP-MC-239-1地下室的楼梯。该楼梯高20格。经探索，确定该地下室约有5层，体积约为50×30×40格。该地下室1~4层每层均有30根由钻石块制成的承重柱，承重柱规律为每5格一根。每根承重柱上均刻有由未知语言构成的碑文。



SCP-MC-239-2位于SCP-MC-239-1地下室的第五层。SCP-MC-239-2以睡姿悬浮在SCP-MC-239-1地下室第五层的中心。SCP-MC-239-2为一名绿型，该绿型外观呈人型，貌龄约100岁，经检测，真实年龄约为[数据删除]岁。SCP-MC-239-2平时呈惰性，经SCP-MC-239-2的身体数据推测SCP-MC-239-2目前正在沉睡。

[[div class="blockquote"]]



**事件：**//沙漠之殇//



**时间：**2024/2/21



**描述：**12:40分，位于SCP-MC-239-1地下五层的监控显示SCP-MC-239-2进行了一次翻身。



SCP-MC-239-2翻身导致了以下结果：

# 驻扎在SCP-MC-239附近1000格的所有工作人员获得5分钟凋零Ⅲ的状态效果。

# SCP-MC-239附近3000格内出现了█████个仙人掌方块。

# SCP-MC-239500格外的区域生成了3只凋灵。

# 驻扎在SCP-MC-239的Site-MC-██内部生成了███只烈焰人。

# SCP-MC-239附近5000格区域的休谟指数上涨了██。



**伤亡：**此次事件导致了Site-MC-██的76.45%设施损毁和所有工作人员死亡。基金会在此次事件中死亡███人，平民死亡████人。



**处理：**在事件发生█分钟后，基金会派MTF-Creeper-01（//“苦力怕爱好者”//）前往Site-MC-██。MTF-Creeper-01清除了所有SCP-MC-239附近的异常后，利用斯克兰顿现实稳定锚稳定了SCP-MC-239。并对这场事件的所有非基金会的目击者进行了B级记忆删除。



**结语：**此次事件后基金会将封锁区域从1000格改到10000格，并给SCP-MC-239附近装配了斯克兰顿现实稳定锚。

[[div class="blockquote"]]



**//绿洲协议//**



**存在原因：**//沙漠之殇//事件后，基金会检测了SCP-MC-239-2，发现SCP-MC-239-2的脑部神经部分活跃。经鉴定，推测SCP-MC-239-2目前已苏醒了10%。为了防止SCP-MC-239-2苏醒导致的HK封神镇压情景，基金会制订了以下措施：

# 启用基金会在全球部署的斯克兰顿现实稳定锚。

# 告知人类基金会的存在，并引导人类接受异常。

# 武装所有基金会人员，随时准备投入战斗。

# 大规模投放模因疫苗//ꙮ-5685//。

# 联合一切国家和GOI镇压SCP-MC-239-2。

# 利用一切可利用的手段镇压SCP-MC-239-2。

# 在成功镇压SCP-MC-239-2后，重建人类文明，并在成功重建后对全人类进行E级记忆删除。

# 至少保证1%的人类存活。
