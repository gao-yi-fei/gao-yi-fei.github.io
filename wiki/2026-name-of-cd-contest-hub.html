成就

+ 展开成就评选办法

本次竞赛引入了成就系统。成就评选与奖项评选相互独立，以下是成就评选办法：

所有在投票截止时分数≥+2的作品都可以参与成就评选，包括含有成人内容的作品、同一作者的多篇作品、合著作品等。

每个成就有且仅有1位得主。每篇文章可以同时获评多个成就。

在竞赛结束时，如果同时有多篇作品符合某成就的要求，则分数较高的作品获得成就；若分数一致，则发布较早的作品获得成就。

部分成就需要事先在讨论区内声明才有获评资格。在成就列表中，此类成就的名称已由标出。

成就将在竞赛结束后由主办方进行统一评选并颁奖。

每个成就都有相应的“点数”。成就奖项的内容即是与点数数值相同的人民币现金红包。成就奖项不是此次竞赛的重点，希望各位作者不要因追求成就奖项而影响作品质量。

此成就评选办法的最终解释权归竞赛主办者Andy_W7所有。

竞赛规则

= 1.主题及其解释

1.1 在本次竞赛中，参赛者必须从Minecraft已有的##DA2221|唱片DA2221|名称##为主题完成作品。

1.2 关于Minecraft已有的唱片及其名称，参见中文Minecraft Wiki的“音乐唱片”页面。可用的唱片为截止2026年8月8日23时59分前，已至少在一个Minecraft版本（包括快照版、预览版）中实装了的唱片。若Minecraft在此时间前删除了原有的唱片，则此唱片仍然可被选择。

1.3 务必注意，竞赛的主题##DA2221|不是唱片本身，不是音乐，不是唱片机##，而是唱片的。对于唱片名称的理解，无需同音乐内容相联系（当然，参赛者仍可以选择这条理解路径）。

1.4 可以选取多个唱片名称。

1.5 本页面中的引文部分不作为对竞赛主题的规范、要求或提示。

= 2.参赛方式

2.1 此次竞赛接受##DA2221|SCP-MCDA2221|、故事与GoI格式##类型的参赛作品。作者需在SCP基金会Minecraft官网中发布原创作品，并在标签中加入“2026唱片之名竞赛”。在作品发布后，作者应在24小时内于评论区说明自己选取的主题（唱片名称）。

2.2 成人内容可以参赛，但不参与评奖，仅参与成就评选（见后文）。

2.3 单个作者可以发布多篇作品（包括合著），但仅最早发布的作品参与评奖。

2.4 先行完工的草稿可以参赛，只要它们从未被正式发布。

2.5 作品发布后可以编辑，但对作品内容的大规模编辑仅限于投稿截止之前。

2.6 竞赛结束时，按照页面分数从高到低排序作为名次。若分数相同，则upvote比例更高者名次更高；若upvote比例仍相同，则先发布者名次更高。

= 3.参赛规范与道德

3.1 严禁违背创作道德的行为，如抄袭、人身攻击、利用规则漏洞等。

3.2 严禁以非正常手段对分数进行操作，如自up、在其他作者发布作品后短时间内downvote、煽动他人对其他作者的作品打分等。竞赛期间，严禁通过Wikidot私信系统向他人推送参赛作品。

3.3 一旦页面发布，请勿自删页面，否则您会被取消参加资格。一般删帖流程仍适用于已发布的参赛页面。

= 竞赛规则（包括赛程与奖品设置）的最终解释权归竞赛主办者Andy_W7所有。

# 每个成就有且仅有1位得主。每篇文章可以同时获评多个成就。

# 在竞赛结束时，如果同时有多篇作品符合某成就的要求，则分数较高的作品获得成就；若分数一致，则发布较早的作品获得成就。

# 部分成就需要事先在讨论区内声明才有获评资格。在成就列表中，此类成就的名称已由**##71B1E3|蓝色##**标出。

# 成就将在竞赛结束后由主办方进行统一评选并颁奖。

# 每个成就都有相应的“点数”。成就奖项的内容即是与点数数值相同的人民币现金红包。成就奖项不是此次竞赛的重点，希望各位作者不要因追求成就奖项而影响作品质量。

# 此成就评选办法的最终解释权归竞赛主办者[[*user Andy_W7]]所有。

= [[size 150%]]**1.主题及其解释**[[/size]]



**1.1** 在本次竞赛中，参赛者必须从Minecraft已有的##DA2221|**唱片**##中选取至少一个，并以其##DA2221|**名称**##为主题完成作品。



**1.2** 关于Minecraft已有的唱片及其名称，参见[https://zh.minecraft.wiki/w/%E9%9F%B3%E4%B9%90%E5%94%B1%E7%89%87 中文Minecraft Wiki的“音乐唱片”页面]。可用的唱片为截止2026年8月8日23时59分前，已至少在一个Minecraft版本（包括快照版、预览版）中实装了的唱片。若Minecraft在此时间前删除了原有的唱片，则此唱片仍然可被选择。



**1.3** 务必注意，竞赛的主题##DA2221|**不是唱片本身，不是音乐，不是唱片机**##，而是**唱片的[[size 150%]]##DA2221|名称##[[/size]]**。对于唱片名称的理解，无需同音乐内容相联系（当然，参赛者仍可以选择这条理解路径）。



**1.4** 可以选取多个唱片名称。



**1.5** 本页面中的引文部分不作为对竞赛主题的规范、要求或提示。

= [[size 150%]]**2.参赛方式**[[/size]]



**2.1** 此次竞赛接受##DA2221|**SCP-MC**##（包括SCP-MC-001提案、搞笑SCP-MC、已解明SCP-MC）##DA2221|**、故事与GoI格式**##类型的参赛作品。作者需在SCP基金会Minecraft官网中发布原创作品，并在标签中加入“2026唱片之名竞赛”。在作品发布后，作者应在24小时内于评论区说明自己选取的主题（唱片名称）。



**2.2** 成人内容可以参赛，但不参与评奖，仅参与成就评选（见后文）。



**2.3** 单个作者可以发布多篇作品（包括合著），但仅最早发布的作品参与评奖。



**2.4** 先行完工的草稿可以参赛，只要它们从未被正式发布。



**2.5** 作品发布后可以编辑，但对作品内容的大规模编辑仅限于投稿截止之前。



**2.6** 竞赛结束时，按照页面分数从高到低排序作为名次。若分数相同，则upvote比例更高者名次更高；若upvote比例仍相同，则先发布者名次更高。
