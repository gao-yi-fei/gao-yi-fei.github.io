# 起初，创世之前，就有四位领主存在。
# 最年长者名“创造”，最年幼者名“行动”，其余两位名“学识”与“远见”。
# 一瞬，领主们顿觉这世间太过寂静了，“创造”言：“有聊胜于无。”，于是领主们开始创造世界，此瞬即为“晨”
# 第一日，“创造”言：“世界应明亮。”于是世界变得明亮。
# “行动”撕裂虚无，于是“虚空”现于世。
# 第二日，“学识”言：“万物不可在虚空中活。”于是“创造”创造出黑方体，坚不可摧，名方块，又名基岩。
# 四位领主拿起方块，置于虚空中。
# 第三日，“行动”与“远见”言：“如此效率，创有之事必亡。”于是“创造”重塑“方块”之形体，又赋于它们生命，于是诸神与祂们的王现于世。
# “远见”言：“你等现于世间，即是为了帮助我等创有。”
# 于是“创造”赐予诸神方块，诸神就围绕虚空放置方块。
# 第四日，“创造”言：“世间不应只有那黑色之物。”
# 于是“创造”拿起方块，重塑其本质。
# 先是红色的残片，名火，又是蓝色的液体，名水，再是棕色的方块，名土，后是无色的物体，名风。
# 然后，“学识”将这四种方块混合，又造新方块，“行动”见，便效仿，于是诸方块现于世。
# 第五日，“远见”言：“如果没有物维护我等所造之世界，创有之事必亡。”
# 于是“创造”又造物，此物与诸神相似，名“园艺师”
# “远见”言：“你等为维护我等所创之世。”
# 第六日，诸神言：“我等已工作许久，应有休息之日。”
# 领主们言：“应有。”
# 于是诸神们与他们的王休息了。
# 第七日，领主见诸神们淫乱，于是便愤怒，便要审判他们。
# “远见”言：“诸神应变为兽。”“行动”与“学识”赞同，但“创造”言：“诸神背叛我等，必需灭亡。”
# 于是诸领主争论不休，便开始争斗了。
# 诸领主争斗，于是虚空分裂成了几个维度。
# 最后，“创造”战败，于是他便成了“[已损坏]”
# 诸神便成与他们的子嗣无异之物。
# 可“[已损坏]”仍不放弃，于是他便创造了深红王与大地之主。
# 其他的领主也仍恐惧他，于是便创造了天域的神与大海之主。
