项目编号：SCP-MC-701

项目等级：Keter（潜在 Apollyon）

特殊收容措施：SCP-MC-701因所处位置未知而无法收容。正在尝试通过间谍活动获知其藏身处。

SCP-MC-701名下的“自我实现”公司势力过于强大，所以基金会目前表面上与其相安无事。暂时已与该公司达成协议，禁止其在任何基金会站点周围10,000格范围内设立门店。MTF-MC-Bedrock-10“告示牌”的反宣传行动已秘密开展，旨在遏制该公司的扩张。禁止一切基金会人员在未经O5-MC议会批准的情况下与该公司发生商业或劳动关系。

描述：SCP-MC-701是俗称“大老板”的未知人形生物。

项目在约十年前创建“自我实现”公司，利用大量疑似具有认知危害的广告向民间推销商品、雇佣廉价劳动力（诸如：“一切个性集中于这些产品！来这里找到你自己！” “想奉献社会吗？快来加入我们！”），迅速扩张为当前规模，并依然不断巩固其垄断地位。

目前“自我实现”公司的业务范围涵盖几乎所有生产部门，其门店已遍布主世界，且正在向下界、末地扩张。所经之处的自然、人工环境都被一定程度地改造，以体现该公司宣扬的艺术风格。目前世界几乎所有民众的生产与消费活动都与该公司有所关系，这一关系大多数情况下会带来严重的精神甚至身体损害，其世界范围内的总和可能会引发K级情景。

项目发迹前的身份信息已丢失，且确信目前只有极少数“自我实现”公司高层员工能见到项目。

+++ 事故记录701-A

当事人：Dr. X█、Dr. Xia

20,208月20日，Dr. Xia作为一名间谍被遣往应聘成为“自我实现”公司员工。27日，开始拒绝与基金会合作。30日起，完全断绝通信。

20,209月2日，Dr. X█随两名安保人员前往该公司谈判，旨在赎回Dr. Xia。
------
采访者：Dr. X█

受访者：“自我实现”公司人事管理部负责人

受访者：先生，你们这样大动干戈来我们这里，是为何呢？

采访者：是为了要回我的朋友。他姓Xia，十二天前成为贵公司的员工，三天前开始杳无音讯。我很担心他的人身安全。希望您能配合我，这对你我双方间的关系大有裨益。要是您想用废话拖延时间，我也愿意奉陪到底。

受访者：您保证？这好极了！最近的工作很无聊，我正想随便找个同等见识的人聊聊天。我保证Xia先生今天能随同您回去，只要您愿意和我聊天。

采访者：嘿，这有何难？我完全可以在这里坐到天荒地老，只怕您不肯与我互诉衷肠！那么，还希望不吝赐教：你们的“大老板”是个怎样的人？

  受访者：这我还真不该详细告诉您。但出于对您的尊重，我也不会用我们广告里那一套来敷衍了事。这么说吧，大老板确实是一个存在的人。但仅仅把他看作一个人是不够的——他是“扩张欲”的化身——换句话说，他是敝公司的渴望无限自我增值的财富的人格化，除此以外他和我们没有区别。但这也仅仅是目前的状况——他将在未来升格为神，“扩张之神”，“扩张”理念在人间的代言者。在敝公司停止扩张之前，他是不死不灭的。而一旦我们停止扩张，那也就意味历史的终结——世界资源枯竭，意味着我们的灭绝。因此可以说，他是与天齐寿。

采访者：扩张！但你们又要怎么做到一直扩张到世界末日呢？

受访者：道理很简单——只要有人愿意为我们出卖劳动、愿意购买我们的产品，我们就能扩张。的确，有需求的人才会消费，而在我们这个衣食无忧的世界，理论上人人都能自给自足。但这并不意味着人们就不需要我们的产品了。人们物质丰厚，我们就让人们的精神空虚。我们用形形色色的广告和产品在人们的心灵挖出另一个胃，一个永远不会满足的胃。我们的广告多巧妙！——“找到你自己！”你也明白，人一旦来到世间就如白纸，摄入世间的食物和水，交往着世间的他人，耳濡目染着世间的声色，他的“自我”早就消亡了——事实上也从未存在过。是我们发明了“自我”，是我们创造了人们的“自我”。我们的工具是广告和商品，所以他们追求的“自我”，也不过是我们的广告和商品罢了。

采访者：这只不过保证了有人愿意买你们的产品罢了，但购买只是交换，并不会增长贵公司的财富。只有劳动才会。那么你们要如何保证人们愿意为你们出卖劳动？

  受访者：这个道理就更简单了——人们爱上了敝公司！我们让人们爱上了他们的“自我”，而他们又要从我们的商品里找到“自我”——然后便是爱屋及乌的道理。是爱让双方融合。人们为我们劳动，感觉就像为自己劳动一样——这是多么幸福的感觉！但是他们为什么不直接为自己劳动呢？这就是我们广告的效果了：“想奉献社会吗？”这又是个好噱头！为自己劳动，只有对自己有意义，但是为社会劳动，就有了更大更广的意义。其中“社会” “意义”也是我们发明的。我们发明的东西，就这样丰富人们的精神，让人们体验到被填充的幸福。并且，为“社会”劳动，也等于为敝公司劳动。因为敝公司支配着世间的财富，支配着世人的命运。所以，我们等于“社会”，敝公司的扩张，也等于社会的扩张，等于人们的“自我”的扩张——尽管这不过是一种感觉，但感觉也就等于实在。不断的扩张也就要求不断的填充，人们又会不断地为我们劳动了。

采访者：感谢您的高谈阔论。不过我想我得反悔了——我要赶时间，所以我得适当地挫败您的口若悬河：您刚刚的一番理论完全没有超出我已知的范围，只是更加坚定了我对贵公司的认识。

受访者：啊......没有给予您丝毫新见闻，真是让给我感到遗憾与自责。我这人也是乘兴而来，兴尽而返。我得回去了。——喂，麻烦把Xia先生请来！

<墙角的一块砖向里收缩，露出一个投掷器。投掷器弹出一柄斧，其刃部纹理与Dr. Xia平日所穿衣物相似。墙砖复位>

采访者：您别和我开玩笑！我是来要人的，不是来讨斧子的！

受访者：很遗憾地告诉您，Xia先生在我们的林业部门工作，负责组织策划大规模森林采伐。他太爱他的工作，后来忍不住亲力亲为。因为陷得太深，他自己就变成了斧的样子。我绝对没骗您，我们不会这么无聊。

采访者：我相信您。以后有事还来请教。再见。<捡起斧离去>

受访者：再见。

3日，Dr. X█在炼药锅内装满B级记忆消除药剂，将斧投入其中，在旁观察。半日后，斧恢复为人形。
------
采访者：Dr. X█

受访者：Dr. Xia

受访者：天啊！我怎么一下子站在一口锅里了！

采访者：我昨天把你从SCP-MC-701的魔窟里救了出来。显然你在那儿的潜伏经历对你造成了严重的身心伤害。你现在开始必须一直待在这个房间里供我观察，想说什么就对我说。

受访者：我想念在公司的一切。公司以经成为了我的生命；离开了公司，我将不我！我爱大老板！

采访者：您在说什么呢？你就是你！你不过是你的身体和精神，这两者又是你一切经历的总和。你和外界是一体的，不分彼此的。所以不要再去想什么“我”不“我”了。

受访者：你说得很有道理。但是......我还是想要仔细想想什么是“自我”与“外界”的边界何在......这个问题我之前从未考虑过，但是经历了这些，又听到了你这些话，它突然进入了我的意识。

采访者：这个问题到底是没有意义的。你不会想出任何结果。

受访者：您走吧，让我自己考虑考虑。有事我会叫您。再见了。

采访者：再见。<离开并锁门>

<4日早，采访者打开门，看见受访者体型小了一半>

采访者：您怎么了？怎么变得这么小了？

受访者：是这样的......我昨天晚上想到，我确实不该从公司那里寻找自我。因为“自我”，我认为，是一种看不见摸不着的“本质”，蕴含于“物自体”，与“公司” “身体”之类的“表象”毫无关系。于是我一下子感到好虚无......但不是说“我思故我在”么？我想，只要能剥离肉体，剥离感官，只留下意识，自我就找到了。一念间，我如有神助，获得了剥离的能力！于是我在夜里不断把自己剥离。到了早上就是这样了。你也能剥离吗？还是说只有我能这样做？

采访者：<努力尝试未果>我想我不能。这可能是SCP-MC-701带给你的自杀能力。总之......你这套“本质” “表象”的说辞与空话无异......

受访者：停！快了！我要达到那个境界了！<突然从身体表面褪下一堆颗粒，导致外貌彻底模糊，几乎为纯红色>我已经剥离了感官！好静谧好幽深啊！

采访者：快停下！！

<受访者显然已听不见这句话，继续剥离身体，最终完全消失>

>> **受访者：**你说得很有道理。但是......我还是想要仔细想想什么是“自我”与“外界”的边界何在......这个问题我之前从未考虑过，但是经历了这些，又听到了你这些话，它突然进入了我的意识。

>> 

>> **采访者：**这个问题到底是没有意义的。你不会想出任何结果。

>> 

>> **受访者：**您走吧，让我自己考虑考虑。有事我会叫您。再见了。

>> 

>> **采访者：**再见。//<离开并锁门>//

>> 

>> //<4日早，采访者打开门，看见受访者体型小了一半>//

>> 

>> **采访者：**您怎么了？怎么变得这么小了？

>> 

>> **受访者：**是这样的......我昨天晚上想到，我确实不该从公司那里寻找自我。因为“自我”，我认为，是一种看不见摸不着的“本质”，蕴含于“物自体”，与“公司” “身体”之类的“表象”毫无关系。于是我一下子感到好虚无......但不是说“我思故我在”么？我想，只要能剥离肉体，剥离感官，只留下意识，自我就找到了。一念间，我如有神助，获得了剥离的能力！于是我在夜里不断把自己剥离。到了早上就是这样了。你也能剥离吗？还是说只有我能这样做？

>> 

>> **采访者：**//<努力尝试未果>//我想我不能。这可能是SCP-MC-701带给你的自杀能力。总之......你这套“本质” “表象”的说辞与空话无异......

>> 

>> **受访者：**停！快了！我要达到那个境界了！//<突然从身体表面褪下一堆颗粒，导致外貌彻底模糊，几乎为纯红色>//我已经剥离了感官！好静谧好幽深啊！

>> 

>> **采访者：**快停下！！

>> 

>> //<受访者显然已听不见这句话，继续剥离身体，最终完全消失>//
