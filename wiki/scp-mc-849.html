描述：SCP-MC-849为一类新发现的史莱姆变种。其似乎为某种异常苹果——“青苹果”编号为SCP-MC-849-A。——和史莱姆的结合体。

类似于一般史莱姆，其由外层黏液和内部核心构成。项目的黏液呈现“诱人的亮绿色”，称为“浓青苹果酱”编号为SCP-MC-849-J。。内层的史莱姆核心有一定程度的青苹果化：其为一个正二十面体，颜色为较深的“诱人的亮绿色”，并在其上半部分有类似苹果的反光。在核心最上方附着了一段外观类似于一般苹果的枝状部分的物体。

项目拥有超超大、超大和大三种尺寸，每种尺寸的长和宽均相同，分别为2.4（二点四）格、1.2（一点二）格和0.6（〇点六）格。其尺寸有着如下的计算公式： 0.55 \times \left( [\text{Size}] + 1 \right) : 式中， : [[$ [\text{Size}] $]]——史莱姆尺寸计算公式中的变量[[$ [\text{Size}] $]]，1。 超超大、超大和大型SCP-MC-849对应的[[$ [\text{Size}] $]]分别为为3（五）、1（二点七五）和0（〇）。]]

可以使用（空）桶或玻璃瓶对项目进行“取黏液”操作类似于对羊的“剪羊毛”。，以得到SCP-MC-849-J。被桶取黏液后项目的外层黏液厚度会变薄到原来的二分之一（50%），此时无法再对项目进行取黏液操作。给项目喂食浆果、蛋糕、曲奇、糖等甜味食物可以令项目黏液层立刻恢复。等待3（三）分钟项目的黏液层会自动恢复。用玻璃瓶不会令项目的外层黏液产生损耗。取10（十）次黏液后，项目的尺寸会变大一个等级。被取过黏液的项目不会攻击曾经对其进行取黏液操作的个体。对不同尺寸的项目进行取黏液操作得到的SCP-MC-849-A不同如对大型项目取黏液得到的为“大桶浓青苹果酱”或“大杯浓青苹果酱”，但实际上不同酱或果汁的大小和效果是一样的。，且无法互相堆叠。

可以将桶内浓青苹果酱放于炼药锅中，加入水可以将其稀释为“青苹果酱”。再次加入水可以将其稀释为“青苹果汁”。三者都可以使用玻璃瓶或桶装起。

将浓青苹果酱置于烟熏炉中可以将其制成“特浓青苹果酱”。在酿造台处，若将特浓青苹果酱作为影响材料，以粗制的药水为基础，可把1（一）份特浓青苹果酱制成“青苹果提取物”。青苹果提取物没有喷溅或滞留形式。

在工作台处使用一瓶青苹果提取物和一个无异常苹果可以合成一个SCP-MC-849-A。

杀死任意SCP-MC-859会掉落数点经验，杀死大型SCP-MC-849会额外掉落1（一）个SCP-MC-849-A。

使用SCP-MC-849-A、SCP-MC-849-J和两者的大部分孪生物会回复数点到十数或数十点不等的饱食度，同时会获得持续一段时间的名为“绿浸Greening”之状态效果。其图标为一个SCP-MC-849-A的像素平面图。该状态效果可以分为不同等级。观察实验得到其为受体带来了持续的“舒适感”、“清爽感”和“愉悦感”的结果。同时随着等级上升，该状态效果为受体提供的正面感觉呈指数增长。该状态效果同时将给予受体小幅度的迅捷、生命回复、抗性提升等正面状态效果中的一种或几种。

食用SCP-MC-849-A将花费2（两）秒，会回复5（五）点饱食度并获得持续一整日的七级绿浸状态效果。

食用桶装之SCP-MC-849-J将花费5（五）秒，会回复9（九）点饱食度并获得持续一整日的四级绿浸状态效果。

持续的过强绿浸状态效果可能使受体上瘾即“浸绿瘾”，也称为“青苹果瘾”，亦称为SCP-MC-849-D。，轻度的SCP-MC-849可以在一定程度上被治愈，危重度的SCP-MC-849会令个体对绿浸状态效果产生不可逆转的病态依赖。任何可以带来高等级绿浸状态效果一般为五级及以上，不同个体间可能存在微小差异，在不同物种之间造成SCP-MC-849-D的绿浸状态效果等级相近。的包括但不限于食品、饮品或使用品需要经过获得资格许可的医务人员或高等级（权限）人员允许后方可领取并使用。

绝大部分的观察实验得到SCP-MC-849-A和SCP-MC-849-J与之孪生物带有适中的酸甜口味之结果。

关于SCP-MC-849-J及其孪生物和SCP-MC-849-A的更多使用方法请参见附录849-APPLE。

SCP-MC-849的生成方法如下：

可以使用一（1）枚嗅探兽蛋、一（1）份青苹果提取物和一（1）枚黏液球在工作台处制作SCP-MC-849的刷怪蛋。

分别给两只同尺寸SCP-MC-849喂食苹果，使得其进入繁殖模式。

每次取黏液时，有0.001%（十万分之一）的概率生成一只超大型项目。

杀死非大型项目时，其会分裂为3（三）个尺寸小一等的SCP-MC-849个体在某些情况下，分裂出的项目会高速飞出。，并拥有被杀死项目个体的名称和状态效果。

给无异常史莱姆喂食SCP-MC-849-A，其会转变为一只SCP-MC-849。

SCP-MC-849跳跃前进。SCP-MC-849的跳跃能力与一般史莱姆相同：超超大型项目对应大型史莱姆，超大型项目对应中型史莱姆，大型项目对应小型史莱姆。项目的寻路能力和一般史莱姆相仿。

SCP-MC-849不会受到渗浆状态效果和剧毒状态效果。

由于大型项目过大，一般其不会被青蛙吞食。

在项目被攻击、跳跃、杀死等时，会播放正确的动画和音效。若某个体被项目杀死，会其显示“被跳跃青苹果杀死了。”

前言：本附录为SCP-MC-849-J和SCP-MC-849-A的各种使用方式与849-J或849-A之部分孪生物的外观、合成方式和使用方式等内容的简要记录。可以在Area-MC-Honi的数据库中得到本附录的完整线上版本。

名称（编号）：青苹果酱

外观：有着849-J比略淡的颜色且黏稠度接近蜂蜜的澄清液体。

材料：一份桶装之849-J，一份桶装之纯水。

工具：炼药锅，空桶（或空玻璃瓶），金剑或类似的长的搅拌棒。

步骤：

清洁炼药锅、空桶（或玻璃瓶）。

将纯水倒入炼药锅中，等待液面重归平静。

一边搅拌，一边将849-J缓慢倒入炼药锅。

注意不要让锅中液体溅出。

当水在849-J分散为许多聚集的不同小液滴时，停止搅拌。静置直到其互相融合。

分装锅中内容物。

清洁工具。

用途：

直接食用。

食用桶装之青苹果酱将花费约5（五）秒，可回复9（九）点饱食度，并获得一整日的三级绿浸状态效果。

**描述：**SCP-MC-849为一类新发现的史莱姆变种。其似乎为某种异常苹果——“青苹果”[[footnote]]编号为SCP-MC-849-A。[[/footnote]]——和史莱姆的结合体。



类似于一般史莱姆，其由外层黏液和内部核心构成。项目的黏液呈现“诱人的亮绿色”，称为“浓青苹果酱”[[footnote]]编号为SCP-MC-849-J。[[/footnote]]。内层的史莱姆核心有一定程度的青苹果化：其为一个正二十面体，颜色为较深的“诱人的亮绿色”，并在其上半部分有类似苹果的反光。在核心最上方附着了一段外观类似于一般苹果的枝状部分的物体。



项目拥有超超大、超大和大三种尺寸，每种尺寸的长和宽均相同，分别为2.4（二点四）格、1.2（一点二）格和0.6（〇点六）格。[[footnote]]其尺寸有着如下的计算公式：

[[div style="overflow-x: auto;"]]

[[math]]

0.55 \times \left( [\text{Size}] + 1 \right)

[[/math]]

[[/div]]

: 式中， : [[$ [\text{Size}] $]]——史莱姆尺寸计算公式中的变量[[$ [\text{Size}] $]]，1。

超超大、超大和大型SCP-MC-849对应的[[$ [\text{Size}] $]]分别为为3（五）、1（二点七五）和0（〇）。[[/footnote]]



可以使用（空）桶或玻璃瓶对项目进行“取黏液”操作[[footnote]]类似于对羊的“剪羊毛”。[[/footnote]]，以得到SCP-MC-849-J。被桶取黏液后项目的外层黏液厚度会变薄到原来的二分之一（50%），此时无法再对项目进行取黏液操作。给项目喂食浆果、蛋糕、曲奇、糖等甜味食物可以令项目黏液层立刻恢复。等待3（三）分钟项目的黏液层会自动恢复。用玻璃瓶不会令项目的外层黏液产生损耗。取10（十）次黏液后，项目的尺寸会变大一个等级。被取过黏液的项目不会攻击曾经对其进行取黏液操作的个体。对不同尺寸的项目进行取黏液操作得到的SCP-MC-849-A不同[[footnote]]如对大型项目取黏液得到的为“大桶浓青苹果酱”或“大杯浓青苹果酱”，但实际上不同酱或果汁的大小和效果是一样的。[[/footnote]]，且无法互相堆叠。



可以将桶内浓青苹果酱放于炼药锅中，加入水可以将其稀释为“青苹果酱”。再次加入水可以将其稀释为“青苹果汁”。三者都可以使用玻璃瓶或桶装起。



将浓青苹果酱置于烟熏炉中可以将其制成“特浓青苹果酱”。在酿造台处，若将特浓青苹果酱作为影响材料，以粗制的药水为基础，可把1（一）份特浓青苹果酱制成“青苹果提取物”。青苹果提取物没有喷溅或滞留形式。



在工作台处使用一瓶青苹果提取物和一个无异常苹果可以合成一个SCP-MC-849-A。



杀死任意SCP-MC-859会掉落数点经验，杀死大型SCP-MC-849会额外掉落1（一）个SCP-MC-849-A。



使用SCP-MC-849-A、SCP-MC-849-J和两者的大部分孪生物会回复数点到十数或数十点不等的饱食度，同时会获得持续一段时间的名为“[[span class="ruby"]]绿浸[[span class="rt"]]Greening[[/span]][[/span]]”之状态效果。其图标为一个SCP-MC-849-A的像素平面图。该状态效果可以分为不同等级。观察实验得到其为受体带来了持续的“舒适感”、“清爽感”和“愉悦感”的结果。同时随着等级上升，该状态效果为受体提供的正面感觉呈指数增长。该状态效果同时将给予受体小幅度的迅捷、生命回复、抗性提升等正面状态效果中的一种或几种。



食用SCP-MC-849-A将花费2（两）秒，会回复5（五）点饱食度并获得持续一整日的七级绿浸状态效果。



食用桶装之SCP-MC-849-J将花费5（五）秒，会回复9（九）点饱食度并获得持续一整日的四级绿浸状态效果。



持续的过强绿浸状态效果可能使受体上瘾[[footnote]]即“浸绿瘾”，也称为“青苹果瘾”，亦称为SCP-MC-849-D。[[/footnote]]，轻度的SCP-MC-849可以在一定程度上被治愈，**危重度的SCP-MC-849会令个体对绿浸状态效果产生不可逆转的病态依赖。任何可以带来高等级绿浸状态效果[[footnote]]一般为五级及以上，不同个体间可能存在微小差异，在不同物种之间造成SCP-MC-849-D的绿浸状态效果等级相近。[[/footnote]]的包括但不限于食品、饮品或使用品需要经过获得资格许可的医务人员或高等级（权限）人员允许后方可领取并使用。**



绝大部分的观察实验得到SCP-MC-849-A和SCP-MC-849-J与之孪生物带有适中的酸甜口味之结果。



关于SCP-MC-849-J及其孪生物和SCP-MC-849-A的更多使用方法请参见附录849-APPLE。



SCP-MC-849的生成方法如下：

# 可以使用一（1）枚嗅探兽蛋、一（1）份青苹果提取物和一（1）枚黏液球在工作台处制作SCP-MC-849的刷怪蛋。

# 分别给两只同尺寸SCP-MC-849喂食苹果，使得其进入繁殖模式。

# 每次取黏液时，有0.001%（十万分之一）的概率生成一只超大型项目。

# 杀死非大型项目时，其会分裂为3（三）个尺寸小一等的SCP-MC-849个体[[footnote]] 在某些情况下，分裂出的项目会高速飞出。 [[/footnote]]，并拥有被杀死项目个体的名称和状态效果。

# 给无异常史莱姆喂食SCP-MC-849-A，其会转变为一只SCP-MC-849。



类似于普通史莱姆，项目的最大生命值等于其尺寸[[footnote]]此指：[[$ [\text{Size}] $]]——史莱姆尺寸计算公式中的变量[[$ [\text{Size}] $]]，1。

下同。[[/footnote]]的平方[[footnote]]项目的最大生命值可以通过以下公式计算：

[[div style="overflow-x: auto;"]]

[[math]]

\text{[max_health]} = \text{[size]}^2

[[/math]]

[[/div]]

: 式中， : [[$ [\text{Size}] $]]——史莱姆尺寸计算公式中的变量[[$ [\text{Size}] $]]，1； _

[[$ \text{[max_health]} $]]——SCP-MC-849的最大生命值，点。[[/footnote]]，近战攻击伤害等于它的尺寸[[footnote]]含大型SCP-MC-849。[[/footnote]][[footnote]]项目的近战伤害可以通过以下公式计算：

[[div style="overflow-x: auto;"]]

[[math]]

\text{[Size]} = \text{[Damage]}

[[/math]]

[[/div]]

: 式中， : [[$ [\text{Size}] $]]——史莱姆尺寸计算公式中的变量[[$ [\text{Size}] $]]，1； _

[[$ [\text{Damage}] $]]——SCP-MC-849的伤害，点。[[/footnote]]。与一般史莱姆不同的是，项目为中立生物[[footnote]]亦称为“条件敌对生物”。[[/footnote]]。



SCP-MC-849跳跃前进。SCP-MC-849的跳跃能力与一般史莱姆相同：超超大型项目对应大型史莱姆，超大型项目对应中型史莱姆，大型项目对应小型史莱姆。项目的寻路能力和一般史莱姆相仿。



SCP-MC-849不会受到渗浆状态效果和剧毒状态效果。



由于大型项目过大，一般其不会被青蛙吞食。



在项目被攻击、跳跃、杀死等时，会播放正确的动画和音效。若某个体被项目杀死，会其显示“被跳跃青苹果杀死了。”

# 观察成品外观是否和上文描述的外观相同，若无异常[[footnote]]如成品外观并非和上文描述的外观相同、成品名称并未改变为“青苹果提取物”。[[/footnote]]则从成品槽中取下成品。

# 清洁工具。

**用途：**

# 合成SCP-MC-849的刷怪蛋。

 * 合成方法参见描述。

# 直接饮用。

 * 饮用青苹果提取物将花费3（三）秒，可得到持续5（五）日之十级绿浸状态效果。

# 精加工。

**说明：**无。

**名称（编号）：**绿浸沙冰

**外观：**带有极淡亮绿色的冰粒。

**材料：**一份桶装之绿苹果汁。

**工具：**空桶（或空玻璃瓶），炼药锅。

**步骤：**

# 清洁工具。

# 在寒冷生物群系[[footnote]]即冻河、冻洋、冰冻深海、雪原、冰刺之地、雪林、冰封山峰、尖峭山峰、积雪山坡、积雪针叶林和积雪沙滩。[[/footnote]]将绿苹果汁桶从离地面至少20（二十）格高的地方掷向地面。重复本操作五次。

# 分装桶中内容物。

 * 将绿浸沙冰倒于炼药锅中以将其分装于桶中。

**用途：**

# 直接食用。

 * 食用绿浸沙冰将花费3（三）秒，可回复10点饱食度并获得持续一整天的三级绿浸状态效果和一级迅捷状态效果。

**说明：**无。

------

**名称（编号）：**青苹果炖蘑菇鸡煲

**外观：**汤为浓绿色的蘑菇煲，有鸡肉块悬浮或漂浮于其中。

**材料：**一份蘑菇煲，一份瓶装青苹果酱，一份生鸡肉，适量（纯）水。

**工具：**营火或熔炉，空碗，木棍。

**步骤：**

# 清洁工具。

# 将生鸡肉去骨，以青苹果酱腌制，备用。

# 盛装适量水于空碗中，煮沸。

# 生鸡肉放于水中，煮至半生。

# 将生鸡肉取出，备用。

# 将蘑菇煲和生鸡肉混合，煮至全熟，加入适量青苹果酱调味。

# 再煮3（三）分钟。

# 清洁工具，食用。

**用途：**

# 直接食用。

 * 食用青苹果炖蘑菇鸡煲将花费3（三）秒，可以食用三（3）次。食用青苹果炖蘑菇鸡煲会回复10点饱食度和获得持续一整日的一级绿浸状态效果。

**说明：**加入更多的青苹果酱以提升获得的状态效果的等级。加入过多青苹果酱会令食物变得难吃。

**名称（编号）：**附魔青苹果

**外观：**闪着附魔光效的SCP-MC-849-A，名称变为[[span style="color: #55FFFF; background-color: #000000;"]]青色[[/span]][[footnote]]即稀有度为“稀有”。[[/footnote]]。

**材料：**一个SCP-MC-849-A，适量青金石粉，1（一）级经验。

**工具：**[数据删除]

**步骤：**

# 清洁工具。

# 按照为非工具物品进行非魔咒附魔的标准流程为849-A附魔。

# 得到成品。

# 清洁工具。

**用途：**

# 直接食用。

 * 使用附魔青苹果将花费3（三）秒，会回复3（三）点饱食度并获得与使用附魔金苹果相同的状态效果。除此之外会获得持续一整日的三级魔化状态效果[[footnote]]一种提升个体奇术能力的状态效果。[[/footnote]]和十二级绿浸状态效果。

**说明：**魔化状态效果将与绿浸状态效果同时结束，同时附魔青苹果不会使使用者患SCP-MC-849-D。

**名称（编号）：**烤青苹果皮

**外观：**类似于烤海带的小片的薄片物体，颜色为暗绿色，有着黑色斑点分布于上。

**材料：**一个SCP-MC-849-A。

**工具：**营火，一端较尖的木棒。

**步骤：**

# 清洁工具。

# 将849-A去皮，将青苹果皮串在木棒上。

 * 不建议丢弃果肉，可以将其制为细小颗粒，取少量同瓶装蜂蜜、牛奶或瓶装纯水混合均匀后制成“苹果绿饮”[[footnote]]关于“苹果绿饮”的详细信息，请参见附录849-APPLE的完整版本。[[/footnote]]或进行其他精加工。

# 将青苹果皮放在营火边烤，直到其完全变色。

 * 不要烤焦。

# 清洁工具，食用菜肴。

**用途：**

# 直接食用。

 * 食用烤青苹果皮会花费2（两）秒，恢复3（三）点饱食度并获得一级绿浸状态效果。

**说明：**使用实验得到烤青苹果皮“酥脆而略带甜味，还带有标志性的青苹果味”。

**名称（编号）：**绿浸超越

**外观：**

**材料：**一份青苹果提取物，一份附魔青苹果，一份[数据删除]，一瓶龙息，一玻璃瓶的纯净一氧化二氮[[footnote]]一氧化二氮（Nitrous oxide或Dinitrogen oxide），一种危险化学品，无色，气味微甜，有成瘾性。[[/footnote]]，[数据删除]。

**工具：**参见**附录849-APPLE**的完整版本。

**步骤：**参见**附录849-APPLE**的完整版本。

# 直接饮用。
