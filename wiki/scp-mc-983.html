包含组件未归档：评分组件已由页首快照替代

项目编号：SCP-MC-983

项目等级：Safe

特殊收容措施：SCP-MC-983本体被收容于Site-MC-19内部的一个铁制箱子内，关于项目的实验请求应得到Site-MC-19主管允许。SCP-MC-983的子本被放置于基金会站点人员休息区的雕纹书架上，以供基金会人员娱乐。

描述：SCP-MC-983是一本成书，名称为“Minecraft终极食谱”，署名为AovaI_ ant。SCP-MC-983的页数已超过了Minecafrt代码里所规定的书与笔页数的最高上限，且每页大约有900字，SCP-MC-983上记载了许多食物的合成配方1Footnote 1.下称SCP-MC-983-A。 ，但这些合成配方在正常情况下是不可能在合成系统中完成并得到项目所记载的食物。SCP-MC-983的异常效应在于当人员开始阅读其时，将无法控制自己的行为。此时人员的行为皆是为了完成其所阅读到的SCP-MC-983-A。在人员完成SCP-MC-983-A后，无论人员物品栏的第三格是否存在物品，都将在第三格出现一个与人员所遵循的SCP-MC-983-A在SCP-MC-983上记载完成后得到的食物2Footnote 2.下称SCP-MC-983-B。 。

所有SCP-MC-983-B的纹理表现为将食物放于碗中或盘子上。在食用SCP-MC-983-B后，人员将获得一个或多个效果，并改变生命值、饱食度与饥饿值等存在数值变化的机制的数值。

附录1：SCP-MC-983的记载的一些SCP-MC-983-A及其产生的SCP-MC-983-B的效果

菜品名称：黑石炖汤
原材料：黑石x12、岩浆、绿宝石x3、红石粉x7
步骤：
# 将黑石放入熔炉中烧制直到黑石烧烂
# 将岩浆倒入炼药锅，再放入烧烂的黑石
# 等待6分钟，随后撒入红石粉
# 1分钟后，将锅中内容物搅拌均匀
# 用碗盛出锅中内容物，并与绿宝石在工作台上合成。这样，黑石炖汤就完成了
实验结果：在D-MC-23233成功合成出该SCP-MC-983-B后，D-MC-23233食用了该个体，回复了五点饱食度并获得了抗火III与伤害吸收V，在持续了3分钟3Footnote 3.总部时间 后这两种效果消失。
菜品名称：苦力怕炒饭
原材料：苦力怕、火药x64、黄色染料x128、蜂蜜x3
步骤：
# 先将苦力怕切成一组丁，在放入炼药锅中
# 在炼药锅中放入蜂蜜
# 在此过程中不断搅拌
# 再放入黄色染料与火药
# 炒至火药粒粒分明，后将其倒入堆肥桶中。这样苦力怕炒饭就完成了
实验结果：在D-MC-23233成功合成出该SCP-MC-983-B并食用后，D-MC-23233的身边突然生成了一只苦力怕但没有爆炸，其名称为“苦力怕社区——最初之作”。
菜品名称：炼药锅蛋糕
原材料：炼药锅、蜂蜜x3、虞美人x4、蛋x2、苹果、面包x4
步骤：
# 将炼药锅的四个脚切下备用
# 在炼药锅中放入一个面包与一瓶蜂蜜
# 重复上步，放入蛋
# 再放入虞美人
# 重复第二步，放入苹果与炼药锅的脚
# 最后放入面包，这样炼药锅蛋糕就完成了
实验结果：D-MC-23233重复了该SCP-MC-983-A，随后成功合成出SCP-MC-983-B。在食用SCP-MC-983-B后，D-MC-23233回复了十二点生命值，并获得了幸运效果4Footnote 4.共持续了19分钟

Footnotes
  1. 1.下称SCP-MC-983-A。
  2. 2.下称SCP-MC-983-B。
  3. 3.总部时间
  4. 4.共持续了19分钟
