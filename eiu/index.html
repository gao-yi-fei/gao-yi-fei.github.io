模型公式

几何与固定参数

两轴对称胞体的主体半径和高度分别为 R = 6 µm、H = 6 µm，肩部间距 d = 2 µm。接触圆盘半径为 a=Acπ，膜间距为 h。胞外液电阻率取 1 Ω·m，外域半径和半高均为 24 µm。

S=2πR2+2πRH+πa(d−h)

每块面积为 Ak 的膜片分得 Gk = G₀ Ak/S 和 Ck = C₀ Ak/S。几何改变时总电导 G₀、总电容 C₀ 与静息电位保持固定。刺激始终施加于细胞 1 的远端平面膜片，面积 As = πR²。

膜电位与电导输入

令 ui 为细胞 i 的胞内电势变化，φe,k 为膜片外侧电势变化。膜电位 Vm,k 与其静息变化量 vk 分别为

Vm,k=Erest+vk,vk=ui−φe,k

gin(t) 是 5 至 15 ms 的升余弦电导脉冲，反转电位 Erev = 0 mV。脉冲内 gin(t)=g02[1−cos(2π(t−t0)D)]，其中 t₀ = 5 ms、D = 10 ms，脉冲外为零。刺激膜片权重 wk = Ak/As，其余膜片权重为零。

Iin,k=wkgin(t)(Erev−Vm,k)

输入电流取向内为正，净跨膜电流取向外为正。各胞内节点满足跨膜净电流之和为零。

Im,k=Ckdvkdt+Gkvk−Iin,k

胞外导电与联立求解

窄缝与周围胞外液构成同一个导电域。膜面法向电流密度为 Im,k/Ak，远场边界设 φe = 0。径向和轴向通量通过轴对称有限体积离散。

je=−σe∇φe,∇⋅je=0

状态向量 x 包含两个胞内电势和胞外网格电势。膜片关联向量 ak 给出 vk = akTx。C 汇总膜电容，G 汇总膜与胞外电导。令 b = ∑kwkak、Ls = ∑kwkakakT，则

Cx˙+[G+gin(t)Ls]x =gin(t)(Erev−Erest)b

从静息状态 x(0) = 0 出发，以 Δt = 0.025 ms 的隐式 Euler 步进计算到 60 ms。令 gn = gin(tn)，第 n 步求解

[CΔt+G+gnLs]xn =CΔtxn−1+gn(Erev−Erest)b

每步电势用于计算输入电流。窄缝出口电流为各出口导电边电流之和。

对细胞 2 的接触膜和非接触膜分别进行面积加权平均。接触膜峰值取绝对值最大的时刻所对应的带符号电压。

数值检验与适用范围

49 组几何的节点、胞体及窄缝电流守恒残差均低于 10−8 pA。基准几何减半时间步和加密空间网格后，接触区电压曲线的相对最大差分别为 0.00165% 和 1.754%。

模型采用等电位胞内与均匀被动膜。细胞 2 无直接输入时，全膜面积平均电压变化保持零，接触膜与其余膜仍可出现不同方向的局部极化。结果用于比较这一被动模型中的局部耦合。

场耦合与胞外液、膜、胞内的显式建模参考 Goldwyn 与 Rinzel（2016）、Tveito 等（2017）。
